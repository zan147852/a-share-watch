# A股收盘观察系统 v0.3

提供自动行情采集、价格筛选、五步主线证据、冻结题材与次日验证、历史结果、错误状态和适配手机的网页。没有 npm 依赖，Node.js 22 以上即可运行。

## 五步主线证据

网页新增“主线观察”。每个题材分别显示消息级别、首板潮、容量中军、老龙异动、次日验证，状态区分规则通过、待事实复核、条件不符、证据不足、等待验证。各门槛位于`config.json`的`mainline`，未经过盈利验证。

1. 消息：采集截至目标收盘前最近3个自然日的财联社/东方财富公开快讯，按机构和实施动作关键词标记国家级政策、部委政策、地方/产业、公司事件、传闻/否认。新闻原文与业务受益始终需要复核；媒体A/B/C等级不当政策级别。消息时间不保证事件首次公开。窗口完整只代表至少一个来源覆盖，不代表全网覆盖。
2. 首板潮：从全部题材成分中复核目标日未复权涨停价与连续涨停，至少3家收盘首板、至少3家首次封板在09:25—10:30。东方财富涨停池必须核对`qdate`，与原始日线价格及连板数一致才采用首次封板时间。历史接口错日会被拒绝。官方板块20日新高与量比1.2是独立条件；成分上涨比例60%、突破比例20%、平均量比1.2仅作为代理证据，不替代指数。未回封炸板尚未纳入。
3. 容量中军：目标日总市值100亿元以上，按当日成交额选前3只容量候选；至少1只涨2%以上且量比1.2以上。历史重扫缺目标日市值，保持未知，不用今天市值冒充历史。
4. 老龙代理：目标日之前60个交易日，排除最近5个交易日，至少3次复核涨停且曾2连板；前一交易日涨3%以上，目标日涨3%以上且量比1.2以上。题材身份和此前是否真正领涨仍须复核。当前ST排除无法重建过去风险标记。
5. 次日验证：从`public/data/mainline-日期.json`读取实际上一交易日冻结的首板、最高连板领涨候选、中军。领涨平均开盘溢价2%以上，昨日首板今日收盘高于昨日收盘的留存比例50%以上，中军开盘和收盘最低反馈不低于-2%。缺任何冻结成员数据不缩小分母。历史重扫或次日开盘后才生成的名单不参与事前验证。

每日冻结文件写入仓库，缓存只加快请求，不作为唯一历史记录。达到市场日线覆盖门槛的冻结记录不随重跑挑换核心名单；覆盖严重不足的报告允许补跑，并以补全时刻重新冻结，跨日补全不计作事前名单。首次上线没有此前事前记录，需连续运行后才能形成次日验证。五步共振仍是研究证据，不是自动买入指令。

题材范围使用新浪概念成分，排除持仓、指数、大小盘、ST、昨日涨停等非产业题材分类。取目标日可用成分平均涨幅前20个题材，保留昨日观察题材；动态名单不等于固定受益公司名单，也可能漏掉未上涨的新催化。日线预筛宽松寻找可能涨停者，最终按分四舍五入未复权价格核验，并用复权日线排除除权误判。每轮历史复核最多180只，超限或源失败保留未知。

## 当前自动范围

- 全部主板与创业板（包括 301），排除科创板、北交所、ST 和退市名称。
- 先核对上证指数目标日K线；北京时间15:20之前不生成收盘结果。
- 腾讯响应成功但缺目标日K线时继续尝试新浪备用源；缺目标日的旧缓存也不会阻止重新获取。
- B 使用此前10个完整交易日最高价；S 使用此前5个完整交易日最低价。
- 目标日收盘大于B且不超过B上方2%，按收盘价计算到S风险不超过5%。
- 新股历史少于60交易日不纳入初版。
- 候选继续核对完整8根30分钟K线，排除重复时段，并核对日线与分钟实际收盘一致；缺数据不显示通过。
- 前复权数据计算结构，再按目标日未复权收盘换算价格，避免把历史复权数字直接当委托价。
- 采集部分概念板块的指数与成分证据。动态成分只供观察，不等同事前固定题材股票池。
- 历史结果、扫描覆盖率、错误和排除原因保存为 JSON。
- 手动重扫昨日不会把今日涨幅混入昨日排名。
- 不会下单，也不读取券商账户。

v0.2 是收盘观察模式，与原方案盘中突破模式分别统计。收盘超过上限的股票被跳过，不能据此断言其盘中从未出现过信号。

## 本地运行

在本目录执行：

- 启动网页：`node server.js`，打开 `http://127.0.0.1:8787`。
- 指定日期：`node scan.js --date 2026-10-08`。
- 自动当日：`node scan.js`。
- 测试：`node --test test/*.test.js`。

本地服务运行期间，中国时间工作日15:25自动扫描。实例必须持续在线；休市以目标日数据可用性判断，不把工作日直接当交易日。

GitHub 定时任务可能延迟，默认分支必须存在；长期不活跃仓库的定时任务可能停用。免费公开仓库会公开代码和筛选结果，因此不要提交账户资金、成交、持仓或任何密钥。程序不需要 GitHub token。网页本身不能调用需要权限的 GitHub workflow，云端页面提供 Actions 入口。

公开行情接口从海外runner访问仍可能失败；此时网页显示失败或部分数据，不能把接口失败解读为0候选。Actions成功只表示任务和部署完成，还须核对网页的数据覆盖及各项核验状态。

## 消息与手机推送

消息真伪、首次公开时间、公司业务关联和老龙题材身份仍需原文或人工复核；程序已开始自动建立收盘冻结名单与次日留存。价格候选与五步题材清单分别展示，候选仍显示缺失条件，没有完整买入信号。

当前手机查看为网页，锁屏消息推送未配置。选定通知服务后接入并测试到达；不以普通推送替代止损或秒级打板执行。

## 数据口径与边界

- 腾讯、新浪、东方财富公开接口都可能访问失败或改变字段。日线结构采用腾讯前复权数据，备用采用新浪原始日线除以逐日复权因子；实际价格与未复权分钟记录也可来自新浪。不同来源的复权算法可能产生小幅差异。
- 当前名称和成分用在历史重扫时有幸存者偏差，页面明确标记；历史重扫不计作事前选股成绩。
- 板块采集只取当前涨幅排序前30个概念（排除昨日涨停等表现类），可能漏板块。
- 98%覆盖率是数据质量阈值，不是盈利概率。
- 暂未自动计算涨停可成交性、连板、炸板、分红等现金流、成交手续费及交易收益。
- 网页输出是观察清单。明日价格、结构失效位、T+1和流动性仍要复核。
- 策略参数尚未经过盈利能力验证，程序跑通只证明数据与规则能执行。
