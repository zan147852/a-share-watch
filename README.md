# A股收盘观察系统 v0.2

首版提供自动行情采集、价格筛选、概念板块证据、历史结果、错误状态和适配手机的网页。没有 npm 依赖，Node.js 22 以上即可运行。

## 当前自动范围

- 全部主板与创业板（包括 301），排除科创板、北交所、ST 和退市名称。
- 先核对上证指数目标日K线；北京时间15:20之前不生成收盘结果。
- B 使用此前10个完整交易日最高价；S 使用此前5个完整交易日最低价。
- 目标日收盘大于B且不超过B上方2%，按收盘价计算到S风险不超过5%。
- 新股历史少于60交易日不纳入初版。
- 候选继续核对完整8根30分钟K线，排除重复时段，并核对日线与分钟实际收盘一致；缺数据不显示通过。
- 前复权数据计算结构，再按目标日未复权收盘换算价格，避免把历史复权数字直接当委托价。
- 采集部分概念板块的指数与成分证据。动态成分只供观察，不等同事前固定题材股票池。
- 历史结果、扫描覆盖率、错误和排除原因保存为 JSON。
- 手动重扫昨日不会把今日涨幅混入昨日排名。
- 不会下单，也不读取券商账户。

v0.2 是收盘观察模式，与原方案盘中突破模式分别统计。收盘超过上限的股票被跳过，不能据此断言其盘中从未出现过信号。

## 本地运行

在本目录执行：

- 启动网页：`node server.js`，打开 `http://127.0.0.1:8787`。
- 指定日期：`node scan.js --date 2026-10-08`。
- 自动当日：`node scan.js`。
- 测试：`node --test test/*.test.js`。

本地服务运行期间，中国时间工作日15:25自动扫描。实例必须持续在线；休市以目标日数据可用性判断，不把工作日直接当交易日。

## GitHub 免费运行与手机查看

已部署网页：https://zan147852.github.io/a-share-watch/

仓库：https://github.com/zan147852/a-share-watch

1. 手机浏览器打开网页，收藏或添加到主屏幕。
2. 在“查看日期”选择已生成的日期；“筛选候选”可切换主板、创业板或30分钟已核对。
3. 展开候选的“查看规则与缺失条件”，查看价格结构、分钟记录与尚待核验的条件。
4. 云端在工作日北京时间15:25定时触发，手机无需保持网页打开。任务结束后刷新网页查看。
5. “打开云端运行记录”可查看任务是否成功；需要补扫时，在 Actions → “收盘筛选与网页更新” → Run workflow 填写日期。

2026-10-09已验证云端扫描与Pages发布成功。2026-10-08的事后重扫覆盖4408/4419只（99.75%），取得65个价格候选，全部取得实际价格并通过完整30分钟记录核对。11只缺少目标日日线；板块和消息接口本轮获取失败，候选不具备完整买入条件。历史重扫不计作事前选股成绩。

GitHub 定时任务可能延迟，默认分支必须存在；长期不活跃仓库的定时任务可能停用。免费公开仓库会公开代码和筛选结果，因此不要提交账户资金、成交、持仓或任何密钥。程序不需要 GitHub token。网页本身不能调用需要权限的 GitHub workflow，云端页面提供 Actions 入口。

公开行情接口从海外runner访问仍可能失败；此时网页显示失败或部分数据，不能把接口失败解读为0候选。Actions成功只表示任务和部署完成，还须核对网页的数据覆盖及各项核验状态。

本仓库使用`project-bundle.json`同步程序：工作流开始时展开项目包，保留历史`public/data/`并跳过`.github/`。修改程序或README后，在项目目录执行`node build-bundle.js`并上传更新的项目包；工作流文件需单独更新。项目包不含行情缓存、账户资金或持仓信息。

## 消息与手机推送

消息真伪、首次公开时间、公司业务关联，以及事前题材名单、中军、老龙、首板留存还需要独立数据源或人工复核。价格候选始终显示缺失条件，没有完整买入信号。

当前手机查看为网页，锁屏消息推送未配置。选定通知服务后接入并测试到达；不以普通推送替代止损或秒级打板执行。

## 数据口径与边界

- 腾讯、新浪、东方财富公开接口都可能访问失败或改变字段。日线结构采用腾讯前复权数据，备用采用新浪原始日线除以逐日复权因子；实际价格与未复权分钟记录也可来自新浪。不同来源的复权算法可能产生小幅差异。
- 当前名称和成分用在历史重扫时有幸存者偏差，页面明确标记；历史重扫不计作事前选股成绩。
- 板块采集只取当前涨幅排序前30个概念（排除昨日涨停等表现类），可能漏板块。
- 98%覆盖率是数据质量阈值，不是盈利概率。
- 暂未自动计算涨停可成交性、连板、炸板、分红等现金流、成交手续费及交易收益。
- 网页输出是观察清单。明日价格、结构失效位、T+1和流动性仍要复核。
- 策略参数尚未经过盈利能力验证，程序跑通只证明数据与规则能执行。
